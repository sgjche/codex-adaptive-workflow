# A small falsifiable check

Use this branch for one consequential prediction that inspection cannot
settle. A request to list unknowns alone does not authorize a new experiment.

Before running anything, state the assumption, expected observation, and what
would count against it. Choose the smallest reproducible check within the
current scope and resource authorization. Use scratch inputs/outputs and
preserve accepted baselines. Do not substitute a synthetic test for a real
interaction when only the latter answers the question.

Record the input identity, command or procedure, actual observation, and its
limits. Separate support, disconfirmation, and inconclusive evidence. A
dependency error or unavailable instrument is an inconclusive setup result,
not evidence that the scientific or software hypothesis is false.

Stop when the named question is answered or the bounded check cannot answer
it. Explain the result and next discriminating observation, if any. Do not
change an acceptance criterion to make an inconclusive check look successful.
